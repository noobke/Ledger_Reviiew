使用说明

1. 导入

选择一个或多个整册 PDF。系统会在本机工作区保存原件副本，逐页渲染并识别；原件不会被修改。

2. 看结果

按严重度浏览问题清单；点击页卡片查看原图、字段、检查项与签名。红色框为严重问题，橙色为一般问题。

3. 签名确认

签名给出“是某人 / 不是在册人员 / 无法判断”三态。灰区请人工从候选或人员表中选择；人工结论只用于本批报告。

4. 导出

导出为一页一份 PDF，按“站点 / 设备 / 类型”归档，文件名包含日期与原页码。已存在同名文件会跳过。

边界

本工具是辅助筛查，不做合规终裁。手写识别、签名归属均可能有误差，请以原件为准。
